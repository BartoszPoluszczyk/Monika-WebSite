# Shared home-page background

`monika-kitchen-20260909.webp` comes from the photograph supplied by the
project owner as `0750ae68-fb8a-43fc-b423-83b6f6168890.png`.
It retains the complete 1821 × 864 frame and is encoded as WebP for the web.
The source upload is not modified.

The image occurs once in `main/templates/main/home.html`, behind the hero
and About preview. Those two includes suppress their separate portraits.
Other pages retain their existing portraits and backgrounds.

Adjust `--home-photo-focus`, the text width and the readability gradient in
`static/css/home-photo.css`. The navbar is outside this wrapper.
