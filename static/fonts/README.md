# Font for the sidebar signature

`alex-brush.ttf` is **Alex Brush Regular**, used for the four-line sidebar
signature.

- Source: https://github.com/google/fonts/tree/main/ofl/alexbrush
- License: SIL Open Font License 1.1, included in `AlexBrush-OFL.txt`.
- Character set: Latin Extended, including the Polish characters used in
  “Zdrowie zaczyna się od dobrych wyborów”.

The font is served from this project rather than from an external CDN. Body
and heading fonts are unchanged.
